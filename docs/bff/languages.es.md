# Languages Informa la Capacidad de Traducción

`GET /api/languages` devuelve los códigos, nombres y ejemplos de idiomas que admite el traductor. La Interfaz usa ese catálogo en vez de adivinar qué nombres localizados se pueden resolver.

La ruta está implementada por [`read_languages`](../../server/main.py).
