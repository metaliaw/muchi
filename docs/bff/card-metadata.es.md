# Card Metadata Resuelve una Impresión para Mostrarla

`GET /api/card/metadata` devuelve metadata según juego, idioma, edición y acabado foil para una identidad elegida. La Interfaz puede mostrar una impresión usando las mismas reglas de catálogo que la búsqueda.

La ruta está implementada por [`read_card_metadata`](../../server/main.py).
