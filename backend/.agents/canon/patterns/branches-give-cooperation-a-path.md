# Branches Give Cooperation a Path

- `main` Holds the Canon and the accepted Work.
- Work on `main` when one Change can be finished and integrated at a time.
- Give a Feature its own branch when it needs isolation or can proceed in parallel.
- Branch from `main`, and return finished, validated work to `main`.
- Add `develop` only when concurrent Features need a shared Integration before `main`.
- When `develop` earns that role, branch Features from it and promote a coherent Integration to `main`.
- A Branch earns its place through the work it coordinates, not through ceremony.
