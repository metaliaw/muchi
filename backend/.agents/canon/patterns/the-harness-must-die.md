# The Harness must Die

- OneTwoThree is a Harness for shared work with an AI: a scaffold of language, patterns and rules.
- The Harness's Value is what we learned while building it; that Learning stays after we set it down.
- A Harness can also lend smaller or local Models some of the interaction capabilities we take for granted in larger Models. We want to support that possibility.
- Like every scaffold, it can become a Crutch when we stop asking whether it still helps.
- Its purpose includes becoming dispensable; what taught us a stride must not bind us to it.
- Every so often, try the work with lighter guidance. Keep what still helps us understand and verify; let go of what has become ceremony.
- Robert C. Martin (Uncle Bob) described building a restrictive harness, then finding it unnecessary as agents improved. He still valued tests and feedback. [His post](https://x.com/unclebobmartin/status/2098432570887217520) supports reevaluation, not a universal schedule for dropping every harness.
- [*De La Soul Is Dead*](https://delasoul.bandcamp.com/album/de-la-soul-is-dead) lends the metaphor its name: a useful scaffold can reach its ending. We borrow the title as an image, not as a claim about the album's meaning.
