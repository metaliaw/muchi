# Documentación / Documentation

Los documentos mantenidos por el proyecto tienen versión en español e inglés.
Cada pareja conserva la misma estructura, enlaza la versión del otro idioma al
inicio y se actualiza en el mismo cambio. Los contratos, ejemplos de máquinas,
fixtures y otros artefactos no son documentos bajo esta convención.

Project-maintained documents have Spanish and English versions. Each pair keeps
the same structure, links to the other language at the top, and is updated in
the same change. Contracts, machine examples, fixtures, and other artifacts are
outside this convention.

## Convención / Convention

- Keep both language files adjacent and use descriptive, translated filenames.
- Link the English and Spanish versions near the title in both files.
- Keep headings, examples, links, and claims aligned across the pair.
- When a document changes, update both versions in the same change.
- Add a row here whenever a maintained document is created or paired.

- Mantén los dos archivos juntos y usa nombres descriptivos traducidos.
- Enlaza las versiones inglesa y española cerca del título en ambos archivos.
- Conserva alineados los encabezados, ejemplos, enlaces y afirmaciones.
- Cuando cambie un documento, actualiza ambas versiones en el mismo cambio.
- Añade una fila aquí al crear o emparejar un documento mantenido.
