# Infrastructure Costs and Support (UNDISTILLED)

Muchi is running initial tests. Google Cloud infrastructure has a real cost,
but the actual amount for the last completed quarter, July through September
2026, has not yet been retrieved. The public framing “Más barato que un
completo” is an idea for communicating a small cost, not a measured claim.

On October 5, 2026, `gcloud` confirmed billing was enabled and listed four
second-generation functions, one Firestore database, one Cloud Tasks queue,
and two Cloud Scheduler jobs in `southamerica-east1`. `bq ls` found no
BigQuery datasets in Muchi's project. Listing billing budgets failed because
the Cloud Billing Budgets API was disabled; that is separate from access to
Cloud Billing Reports. No invoice or cost report was retrieved.

Possible ways to help pay for the tests include voluntary donations, direct
sponsorship from card shops, and advertising once Muchi has a validated
audience. Any sponsorship or ad should stay visibly separate from search
ranking and compared prices. A comparison to a completo needs a stated local
price and date. The recipient and accounting path for contributions also need
to be decided.

The unresolved story is whether the quarterly cost is small enough to explain
in completo terms, and which support path users and shops would actually value.
The missing bill, payment setup, audience and feedback still shape the work.
